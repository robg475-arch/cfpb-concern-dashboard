# CFPB concerns to watch out for in 2025

CSE 6242 dashboard. Open it here:

https://robgonz_cisco.github.io/cfpb-concern-dashboard/

Choose a company, product, and sub-issue. The map is 2025. Hover a state for the share and the no-relief rates. Product names that the Bureau renamed are folded into one label.

The page loads summary files from `data/`. Opening `project.html` as a local file will not load them. Use the link above, or from this folder run `python3 -m http.server` and open `http://localhost:8000/project.html`.
